## About

Senior full-stack developer working across the **entire JavaScript / TypeScript ecosystem** — not tied to a single stack. I build production web applications end to end: front ends in **Angular**, **React / Next.js** and **Vue**, back ends in **Node.js** (Express, NestJS), and data layers on **MongoDB** and **SQL**. MEAN is where I started; today I pick the right tool from the JS toolbox for each project.

- 🏗️ I design and ship **scalable REST & GraphQL APIs** on Node.js
- ⚡ I build **SPAs** with Angular & React and **SSR / SSG apps** with Next.js
- 🎨 I turn design concepts into **accessible, responsive interfaces** (Angular Material, Tailwind CSS, Bootstrap)
- 🧩 I care about **clean architecture**, TypeScript everywhere, and maintainable code
- 🤝 I work in **Agile teams**, review code, and mentor other developers
- 🚀 Always exploring what's new across the JavaScript ecosystem
